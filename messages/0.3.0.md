Task List 0.3.0
===============

- **Breaking:** `icons` entries now carry their own label, and `legend_labels` is
  gone. Two parallel lists could fall out of sync — a missing label silently
  truncated the legend — so a label now lives on the icon it describes:

  ```json
  "icons": [
      { "icon": "⚛️", "label": "to do" },
      { "icon": "🅿️", "label": "in progress" },
      { "icon": "✴️", "label": "highlight" },
      { "icon": "🆘", "label": "error" },
      { "icon": "✅", "label": "done" }
  ]
  ```

  If you overrode `icons` in your user settings, rewrite it in this form — the old
  flat list still toggles and sorts, it just won't show up in the legend. Any
  `legend_labels` you set is now ignored and can be deleted. `legend_separator` is
  unchanged.
