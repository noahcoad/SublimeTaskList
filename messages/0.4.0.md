Task List 0.4.0
===============

- **Sort reverses a sorted list.** Running **Task List: Sort** on a list that's
  already in icon order flips it, so done work comes to the top; run it again to
  flip back. The status bar says which happened.
- **Blank lines no longer split a list.** A list with blank lines between its
  items sorts as one list, and the blank gaps stay where they were.
- **Sort works from anywhere in an item.** A cursor deep in an item's indented
  notes now finds its task line, instead of doing nothing.
- **"No task list here"** shows in the status bar when the cursor isn't in a list.
- **New default icon order:** 🆘 error → ✴️ highlight → 🅿️ in progress → ⚛️ to do
  → ✅ done. This changes both the toggle cycle and the sort order. If you prefer
  the old order, set `icons` in your user settings.
