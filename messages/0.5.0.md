Task List 0.5.0
===============

- **New: Task List: Alternative Sort.** Sorts a list the same way as **Task List:
  Sort**, but in the order set by the new `alt_sort` setting instead of the toggle
  cycle. The default puts the most critical work first:

  ```json
  "alt_sort": ["🆘", "✴️", "⚛️", "🅿️", "✅"]
  ```

  Icons missing from `alt_sort` sort after the ones it lists, and running it on a
  list that's already in that order reverses it, just like Sort.
- **No suggested hotkey for Sort any more.** Only Toggle has one now. Run Sort,
  Alternative Sort, and Insert Legend from the command palette, or bind them
  yourself; the readme lists each command name. If you already copied the old
  `super+alt+s` binding into your own key bindings, it keeps working.
